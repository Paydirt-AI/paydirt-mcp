# Support

For installation questions and reproducible bugs, open a [GitHub issue](https://github.com/Paydirt-AI/paydirt-mcp/issues). Include the MCP package version, MCP host, Node.js version, iOS dependency manager, subscription provider, and the exact error with credentials and customer feedback removed.

For product documentation and account support, visit [paydirt.ai](https://www.paydirt.ai).

Use [private vulnerability reporting](https://github.com/Paydirt-AI/paydirt-mcp/security/advisories/new) for security issues.
